# Tennis Match Tracker

Web application to track tennis matches and analyze performance over time.

## Features

- Log match results (opponent, score, surface, match type, notes)
- Statistics dashboard (win/loss record, win percentage)
- Recent form visualization
- Surface-specific performance analysis
- Match history with delete functionality

## Tech Stack

- Backend: Python Flask, SQLite
- Frontend: HTML, CSS, JavaScript

## Setup

```bash
# Install dependencies
pip3 install -r requirements.txt

# Run the application
python3 app.py
```

Open `http://localhost:5000` in your browser.
